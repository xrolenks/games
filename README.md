# ricksong.github.io
random projects and games

Live at https://ricksong.github.io/

## Layout

- `index.html` — home page listing the games
- `wasteland/` — Wild Wasteland
- `404.html` — shown for missing pages

## Adding a game

1. Make a new folder (e.g. `my-game/`) and put the game in it as `index.html`.
2. In `index.html`, copy a `<a class="card">` block and point its `href` at `my-game/`.
3. Commit and push in GitHub Desktop.
