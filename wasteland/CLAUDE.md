# Wild Wasteland (`wasteland/`)

## Files (split 2026-11-20, Rick's request; was one `index.html`)

`index.html` = page HTML only, `css/style.css` = all styles, `js/` = the code, loaded by plain `<script>` tags at the end of `index.html` **in this order**: `core.js` (shared variables, `GEAR`, ammo, grid helpers, sight, `say`, localStorage `put`/`get`), `areas.js` (cave, exits, Scraptown `TSEC` + townsfolk, shops/drinks, `buildTown`, `newLevel`), `character.js` (attributes, XP, skills, traits, carry weight, `newGame`), `world.js` (`WMN`/`WMS`, clock, enter/leave area, paper map), `combat.js` (combat mode, provoke, loot + containers, `step`, `attack`, `enemyTurn`, intercom), `people.js` (talking, dialogue window, Michael, trading, body loot window, speech bubbles), `actions.js` (`after`/`busy`/`play`/`tap`, weapon effects, reload/equip, stims, `endTurn`), `sprites.js` (`SPR`, player look, `GUNS`/`POSE`, figures), `draw.js` (scenery, buildings, doors, roofs, cave, camera, `drawIso`, `render`), `saves.js` (`snap`/`restore`), `input.js` (grid mouse/touch, foe info, cursors), `ui.js` (wait, Skilldex, saves window, pause, settings, cheats, character, inventory, keyboard), `main.js` (start-up: `buildCursors()`, restore autosave or `newGame`, title menu, character creator).
- The code used to sit inside one `(function(){ … })()`; now it's plain top-level code shared across the files (no `'use strict'`, same as before). Older notes below that say "near the end of the script" mean `main.js`.
- **Load order matters:** a function is only hoisted inside its own file, so code that *runs while a file loads* (a `var x = f()`, a top-level call) can only use earlier files or its own. That's why `put`/`get` live in `core.js` and `buildCursors()` is called from `main.js`. Code inside functions (run later, during play) can use anything.

## Story and flow

You're a wanderer. In a cave you find sealed **Bunker 9**; a voice on the intercom lets you join if you bring back the **reactor control chip**. Title → Start → character creator (name, sex, hat, shirt) → attributes/tags/traits page → intro → **Bunker 9** (cave, map node `out`). Step on a red **exit square** to open the **world map**; walk freely, discover locations, click the one you're on to enter. The chip is in the **Old Power Plant** (`tower`). **Scraptown** (`town`, next to the bunker) is a safe settlement; **Raider Camp** (`scrap`) is further east. Using the intercom while holding the chip wins.

## Code style — read first

Compact code: many functions are one long line. **Never put a `//` comment mid-line inside a one-line function**: it comments out the rest of the line and breaks the whole game. Use `/* */` or a comment on its own line. Match the terse style.

**Startup load:** `if(auto&&restore(auto))…else newGame()` at the top of `main.js`. Anything `restore()` uses must be defined *above* it; if `restore()` throws, the game silently starts a **new game over the save**. After restoring a test backup, check the last log line is "Session restored." and the HUD is sane. **Old saves must keep loading:** new state gets a default in `restore()`, older shapes are migrated there.

## Rick's standing rules

- **Weapon holds:** the player (and every NPC) carries a weapon **lowered at the side** and **raises it only while the firing animation plays**. Every weapon (and the stim pack, which stays down) has a `POSE[w] = {down, up}` (cells: `g` weapon with muzzle last, `s` sleeve, `e` dark edge, `h` gripping hand). `gunUp()` = firing part of a player attack `FX` (`RAISET`) + `RAISEH` (450 ms). Helpers `dn(g)`, `chest(g,fh,bh)` (rifle, sniper, shotgun across the chest), `up1(g)`, `up2(w,s,sh,fh)`. `GUNS[w]` holds the raised cells; the shot's muzzle (`mz` in `drawFx`, revolver 19) must match the raised barrel. NPCs: gun raiders use `Rd`/`Fd` (`lowSpr`) and swap to `R`/`F` while their shot is in flight (`AIM`); guards `NG` → `NGa`; Michael uses the player's `POSE` (`compGun`, `mPose`, `mSkip`, muzzles `MZ`). `TWOH` is only a fallback.
- The trade window's slide-in has no reduced-motion opt-out (Rick wants it).
- Loot containers are placed **by hand** only (see Containers).
- Players see attribute A as **Dexterity (D)** and L as **Fortune (F)**; the screens say "Attributes" and show only names, no effect text. Speech options say `[Speech]` but never the number needed.
- Only Rick's four traits exist (see Character).
- Fog of war is off by default (`bunker9-fog` must be `'1'`). No CRT scanlines.

## Grid, tiles, areas

Area `W=26` × `H=20` (`restore()` rebuilds older 18×14 areas); index `ix(x,y)`. `T[i]`: 0 floor, 1 crate, 2 cactus, 3 shack wall, 4–7 car halves, 8 rock, 9 bunker door, 10 intercom, 11 townsperson, 12 crop row, 13 stall, 14 adobe wall, 15 stall blocker, 16 footlocker, 17 locker, 18 bar counter, 19 closed door, 20 locked door. `items[i]`: `'s'` stim, `'a'` ammo crate, `'g:<gearId>'` gear, `'c'` chip, `'n'` necklace, `'l:<caps>:<pool>:<rounds>'` loot bundle. `E` enemies, `P` player tile, `BD` bodies, `F` shack floor, `SK` shack.

- `newLevel()` makes desert areas from `lv` (danger tier); `buildCave()` from `CAVE`; `buildTown()` from `TOWN`. Exits: `EX` (east edge) plus open tiles above/below (`isExit`, `openExits`); Scraptown's west gate (x 0, rows 9–11) is also an exit, main-section entry (1,10).
- **Scraptown** is static: rebuilt from its layout every visit and load, never restored from a saved area. Sections `TSEC` (`main` Market, `north` Homes, `south` Farms), each a W×H layout with houses in `hs`; orange `O` tiles in the top/bottom wall (`LK`) lead to the next section (`goSec`, run via `PSEC` once the walk ends). `WMS.tsec` current, `WMS.tvis` visited; on the map, visited sections get buttons (`#wmsecs`), else you enter at the main gate (`enterArea(id,sec)`). Ringed by adobe walls (`#`, `adobe()`/`wbox()`), west gate pillars `GATE` + `gateArch()`. Ground items per section in `WMS.titems[sec]` (`items` is that object while there); `buildTown` moves old items that now sit on a wall/fence to `freeNear`.
- **Town look** (Rick's reference: big flat-roofed buildings along paved streets): Market = general store (top left, stock crates `C`), bar (top right), fenced garden, Alex's stall, small house; Homes = 5 big buildings on a T of streets; Farms = 2 fenced crop fields, barn, farmhouse. All section gaps `O` are in columns 12–13 (the main N–S street). Layout letters `r` street / `p` sidewalk → `GRD` (plain floor, `gnd(i)`, drawn by `ground()`: asphalt with cracks/stains and a dashed centre line, concrete with curbs); townsfolk and `L` lamps take the ground to their left. `x` fence = tile 23 (`fence()`: post + rails back to −x/−y neighbours; doesn't block sight). Buildings use `townBox` (dark riveted sheet metal) instead of `plankBox`, and flat `townRoof` (parapet, tar and gravel, vent box) instead of the pitched roof (`roofPts` flat at `SHH+8` in town). Roofs only fade for people *behind* a building, not inside it (`behindRoof`). Changing layouts shifts tile numbers, so old saves' `thost`/`tdead`/`tdoor` keys may not line up.
- **Townsfolk:** `TOWNNPC` (sprite, role) by layout letter → `NPCS` (`i`, `home`, walk state), `npcAt(i)`. Farmers/villagers wander ≤2 tiles from home (`npcTick`, `NPCW` ms/step); guards, Alex, Rosa stand still. Click → `talkTo(i)`: a line from `TOWNTALK` or their own `l` list. Sprite letter `g` is never drawn in dialogue portraits (it's the guard's rifle), so don't use it for hair or faces. Guards `G`/`NG`: helmet, olive vest, rifle across the chest (letters `r`/`w`).
- **Attacking townsfolk** (combat mode): `provoke()` turns the whole section hostile (`npcFoe`, `e.spr`, `e.nm`); `WMS.thost`/`WMS.tdead` keep it across visits. Named foes keep their names (`nm()`, `fixNames()` turns "the rosa" into "Rosa").

## World map and clock

- `WMN` locations (`t` tier, `safe`, `cave`, `fin`, `ent` re-entry tile, `l` roads, `x/y` on 480×300). `WMS` saved state: `at`, `vis` (entered; names are `???` until then), `seen`, `areas` (snapshots), `pos`, `open`, `time`, `ic`, `chip`, `done`, `noloot`. `wmGo/wmStep/wmSpot/wmInfo/wmEnter/drawMap`; `SEE` discovery range, `WSPD` 30 speed, `MPP` minutes per pixel, zoom `WMZ` 2× following you (`wmCam`). `enterArea()`/`leaveArea()` swap area state; `placeChip()`. The map opens only after the walk onto the exit ends (`!busy()` in `render`).
- **Clock:** `WMS.time` = minutes since day 1 midnight (starts 480). `tick(min)`; steps and combat turns cost 1. Healing every `HEALT` (240 min): `healRate()` = max(1, ⌊E/3⌋), progress `WMS.hl`. Entering a location doesn't heal. `nightF()` 0 by day, 1 from 8 PM–6 AM; night = blue wash + stars (`drawIso`), `drawClock()` on the map.
- **Sunrise/sunset:** `duskF()` 0–1 (sunset 5:30–8:30 PM, peak 7:30; sunrise 5:30–8 AM, peak 6:30), `isDawn()`. `drawIso` paints an orange/pink sky with a low half sun (left at dusk, right at dawn) after the backdrop, and a warm wash after the tiles. Not in the cave.
- **Lights:** `LIGHTS` (emptied each `drawIso`) = `[x,y,radius,flicker]` pushed by `campfire()` (tile 21), `lampPost()` (tile 22, lit when `lightF()` > .15) and lit windows (`wallWin`). `nightWash(alpha,lf)` draws the night wash through stencil canvas `NWC` with soft holes at each light, then adds a warm glow (`lightF()` = max(night, dusk×.6), 0 in the cave). Campfires: `FIRES` per location (`scrap` 2, `road` 1), placed by `fires()` in `enterArea` if the area has none (old saves too), never blocking the exit/shack door. Lamp posts: letter `L` in the `TSEC` layouts. Neither blocks line of sight.
- **Paper map:** `drawMap` draws on `paper()` (cached `PAPER`, 960×600: stains, grain, coffee ring, fold creases, browned edges), brown ink `MINK`, red pencil `MRED` (your pin, trail, X, selection ring), Georgia italic labels, compass `mapRose()`, pocket-watch `drawClock()`. Dusk tints it orange, night dark blue.

## Turns, movement, combat

- `tap(i)` handles clicks, `step(n)` moves, `attack(e)`, `endTurn()` → `enemyTurn()`. Out of combat (`inCombat()` false) walking is free and AP refills in `after(cb)`. `busy()` = animating; `play()` runs queued walk/hit phases; `animate()` weapon FX (`FX`); `kick(ms)` keeps redraws going.
- **Wait** (`#waitbtn` in the Sneak button's old spot, or T): `openWait` → `#waitw` (1/2/4/8 hours, until morning 6 AM / evening 6 PM; `waitMins`, `durTxt`); refused in combat. `doWait` runs `tick` forward over 1–2 s (`WAITING`, part of `busy()`) so the sky visibly changes; healing comes from `tick`. Sneak now lives in the Skilldex and on Z; the status label shows SNEAKING. There's no "Combat over" log line any more.
- Click = walk; double-click (`DBL` 500 ms, `e.detail>=2`) or clicking the destination again mid-walk (`MVT`) = run. Other clicks mid-walk are ignored. Steps `GAITMS` walk 240 / sneak 340 / run 120 ms (`MVG`/`MVD`). Legs: `legs(d,PLEG)` in `pdat()` (w/r/c, `LEGP` phase 0–3, `MVK` parity). Sneak (`SNEAK`, Z or button, saved `snk`): crouched, enemy sight −`SNKR`; a run ignores it.
- Enemies idle until alerted (`e.al`): `detect()` (sight `SIGHT={R:7,r:5}` + LOS), `noise()` on attacks. Melee enemies lunge (`LQ` → `LUNGE` in `play()`, shifted by `drawIso`'s `add()`).
- Log lines: `hitSay(e,dmg,crit)` / `missSay(e)`; multi-hit weapons log the total. Rockets splash within 1 tile (`rocketSplash`). Combat button `toggleFight`/`FIGHT`.
- **Loot:** dead humans carry 5–10 caps + 1–3 magazines (`lootDrops()` in `after()`, also counts kill XP; `BD[k].loot`); click the body → `#loot` (`searchBody/openLoot/takeLoot`). Leaving an area/section turns unlooted bodies into ground bundles (`bodyLoot`), picked up in `step()`. Carried gear can be dropped (`dropBag`); clicking ground gear walks there and `pickUp()`s it; E equips.
- **Death:** `pDead()` → `deathFall()` topples the player (`DEATHF`), then after `DEADW` the `#dead` window (`openDead`: Load / New game).

## Character: attributes, XP, skills, traits

  - A → AP `apFor(A)` = 5 + ⌊A/2⌋ in `MAXAP` (`syncAP()`).
  - S → `carryMax()` = 50 + 10×S lb; `carryW()` (gear `WT`, stims, ammo `AMW`/round, grenades); `overW()` → 2 AP per combat step, half map speed. Shown `.wtrow`, `wtTag()`. Also melee/unarmed damage.
