# Fatal Fists (`fatalfists/`)

One-on-one arcade fighter (no build, no image or sound files: art drawn on a `<canvas>`, sounds made with Web Audio).

**Files (split 2026-11-20, Rick's request; was one `index.html`).** `index.html` = page HTML (canvas, touch buttons, menu screens), `css/style.css` = all styles, `js/` loaded in this order (`'use strict'` each, shared global scope): `data.js` (basics `$`/`rnd`/`ease`, `FIGHTERS`, `MOVES`, poses `P`, settings), `sound.js` (`SFX_RAW`, `SFX` wrappers), `input.js` (`keys`, `KEYMAP`, `humanInput`), `fight.js` (`G`, `NET`, fighter states, `control`, hits, blasts, `separate`), `ai.js` (computer fighter), `update.js` (`step()` + particles), `draw.js` (arena, fighters, blasts, HUD, `render`), `online.js` (PeerJS), `menus.js` (screens, fighter select, buttons, keyboard, touch), `main.js` (`resize` + frame loop). Code that runs while a file loads may only use earlier files. First built 2026-11-20 from Rick's request: "inspired off basic Mortal Kombat mechanics, WASD to move, buttons to kick and punch". Follows the site's originality rule: the mechanics are classic fighting-game ones, but the name, fighters, arena, art and wording are ours. Don't use the other game's terms or characters (no "Fatality", "Finish him", "Flawless Victory", ninjas in its colours, etc.); we say "K.O.", "PERFECT!", "<NAME> WINS".

**Modes:** 1 Player vs the computer (Easy / Normal / Hard), 2 Players on one keyboard, or **Play online** (`G.mode = 'online'`, see below). Best of 3 rounds, 60 s each; time out → more health wins the round (equal = draw, nobody scores).

**Controls (`KEYMAP`):** P1 WASD move (W jump, S crouch), J punch, K kick, L block, I special (F/G/H/T as laptop-sharing alternates; in 1P the arrows and P2 keys also work for P1). P2 arrows + Numpad 1/2/3/5 (or , . / '). Esc/P pauses. On touch devices (`body.touch`) a d-pad and 4 buttons appear (`#touch`, they fake P1's keys); in landscape they float over the game.

**Moves (`MOVES`, frame data at 60 fps):** punch, kick, crouch+punch = uppercut (knockdown), crouch+kick = sweep (knockdown), toward+punch up close = throw (unblockable), air punch / air kick (one per jump), special = energy blast (`SPECIAL_WAIT` 80 frames recharge, one on screen per fighter; two blasts cancel). **Dash (Rick's request after play-testing, 2026-11-20):** double-tap left or right within `DASH_TAP` 14 frames → state `dashf` (toward the rival, `DASH_SPEED` 9.5, ~104 px) or `dashb` (away, `DASH_BACK` 7.5, ~82 px), `DASH_FRAMES` 14 long (`startDash`, taps tracked in `f.lastTap`; left/right are in `PRESSABLE` so taps get buffered and sent online). From frame `DASH_CANCEL` 5 a punch/kick cancels it (dash-in punch). Poses `P.dashf`/`P.dashb`. You can be hit while dashing. Computer (Normal/Hard) dashes in and punches, or back-dashes out of range. Crouching ducks punches and blasts (hurtbox 96 tall vs 150). Block = hold block: blocked hits do 15% chip and blockstun. Inputs are buffered 8 frames (`f.buf`), so quick punch strings combo; the HUD shows "N HITS".

**Fighters (`FIGHTERS`):** Kade (red, balanced, Ember Shot), Vex (purple, Volt Orb: slow + heavy), Rook (brown, slow + strong, Rock Toss), Juno (teal, fast + light, Tide Ring). Each has colours, hair style (`spiky/long/bald/tail`), speed, power, jump and a special.

**Code map:** `G` = all game state. `step()` runs 60×/s (fixed timestep in `frame()`): input (`humanInput` / `aiThink`) → round phases (`intro` → `fight` → `ko` → next round or `showEnd`; phase `over` after the match) → `control` → `updateFighter` → `checkHit`/`applyHit` → `updateProjectiles` → `separate`. Fighter states: idle, walk, crouch, block, cblock, jump, attack, hitstun, blockstun, knockdown (flying), down (lying), getup, ko, win. Hit feel: `G.hitstop`, `G.shake`, `G.slow` (slow-mo on K.O.), `spark`/`dust` particles.
**Drawing:** `buildBg()` draws the arena once (red moon, mountains, wall with fist banners, tiled floor, two fire pillars); `drawFires` animates the flames + embers. Fighters are posed skeletons: `P` = key poses (hip, neck, head, hands, feet), `poseFor(f)` blends them, `ik()` places elbows/knees, `drawFighter()` draws outlined limbs (back limbs darker). `drawHUD` (health bars with red damage trail, special meter, round-win dots, timer, combo text), `drawMsg` (ROUND 1 / FIGHT! / K.O. / WINS).
**Computer fighter:** `AI_LEVELS` (reaction, block, dodge, anti-air, aggression, special chance per level); `aiThink` reacts (block, duck/jump blasts, uppercut jumpers), otherwise `aiPlan` queues steps `{h: held keys, p: press, d: frames}`.
**Menus:** HTML `.screen` overlays (`s-title`, `s-level`, `s-select`, `s-help`, `s-pause`, `s-end`), `show(name)`. Keyboard works in menus (W/S or arrows + Enter/J; select screen A/D + J).

**Online play (PeerJS, Rick's request 2026-11-20).** Same PeerJS as Hex Isles (`PEERJS` = unpkg peerjs@1.5.4, loaded only when needed by `loadPeer`; free public PeerJS server). Screen `s-online`: **Host a fight** makes a 4-letter room code (PeerJS id `ROOM` `fatalfists-room-` + code, retries if taken); **Join** types it in. `NET` = {role 'host'|'guest', side 0|1, conn, peer, picked[2], rheld/rpress (host: guest's keys), ev (host: events to send)}. **The host runs the whole fight** (left fighter) and the guest (right fighter) only sends keys and draws what it gets:
- Guest → host: `{t:'in', h: held-key bits in BTNS order, p: presses}` only when something changes (`guestTick`); `{t:'pause', v}`, `{t:'rematch'}`.
- Host → guest: `{t:'snap'}` every frame (`hostTick`, at the top of `step()`): fighters (`f` arrays), blasts (`p`), round info (`g`: phase, timer, wins, round, msg, sub, msgT, shake, paused) and `ev` = sounds and sparks since the last snap (`netEvent`, called from the `SFX` wrappers and `spark`/`dust`; the guest replays them with `SFX_RAW`). `applySnap` copies it in and opens the end/pause screens.
- Both: `{t:'hello'}`, `{t:'pick', i}` (each picks their own fighter at the same time; host starts with `netTryStart` → `netStart` → `{t:'start', picks}`), `{t:'select'}` (New fighters for both), `{t:'bye'}` (left; `netLeave`). Room full → `{t:'full'}`. A dropped connection (`netLost`) shows "The connection was lost, or your friend left." on the online screen.
- Online, either player can pause (it pauses both), ask for a rematch, or pick new fighters; Main menu / Back leaves the room. HUD labels say YOU / RIVAL. Menu click sounds use `SFX_RAW` so they aren't sent.
- Tested with two Browser pane tabs (host + guest): join, picking, guest keys moving and hitting, K.O.s, end screen on both, rematch from the guest, leaving.

**Saved:** `localStorage` key `fatalfists.settings` = `{muted, level}` only. Clean it up after testing.

**Testing:** the Browser pane is often hidden (rAF paused), so drive the game from the console: `startMatch()` then call `step()` in a loop and set `keys[code]` / `tapped.add(code)`; `render()` then screenshot. All-random P1 vs each AI level ran full matches with no errors (2026-11-20).
